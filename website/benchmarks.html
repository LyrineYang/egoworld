A faster path to the same outputs.

01 / Iteration history

Reduce model reloads and check the output.

Keeping models resident across more clips reduced the cost of repeated loading. These three diagnostic runs kept the original 54 exported hand rows exactly equal. The final setting also changed stage splitting and submission limits, so the measurements describe configurations as a whole.

The accepted filter combines a minimum box area with containment overlap at the original 0.22 confidence threshold. Raising confidence to 0.35 lost left-hand coverage. The selected setting passed the left-hand and bimanual guards on all six evaluated frames in each clip.

02 / Fixed models

An execution comparison with output parity.

EgoWorld and Data-Juicer’s two DefaultExecutor configurations run SAM2, HaMeR and Dex with the same weights, inputs and GPU. The 12-clip medians are 96.82, 119.88 and 114.05 seconds respectively. Seven fixed-model groups matched every audited stage and export field exactly.

What slowed down round five? +
Which outputs were checked? +

The audit compared masks, instances, tracks, hand pose, robot mapping, hand-joint export and robot-joint export. Each full 12-clip execution produced 36 rows per audited category. Numerical arrays and QC matched as well.

The URDF audit found zero limit violations in 195 reference robot rows across the seven groups. Exact parity covers 585 rows across all three executors. Fingertip forward kinematics passed for the reference rows.

03 / Native hand products

The fastest hand export has a different quality profile.

On the development set, EgoWorld’s median whole-run time was 81.03 seconds. Native Data-Juicer took 156.78 seconds on CPU, 49.09 seconds on CUDA, and 39.20 seconds with CUDA mesh and visualization exports disabled. This track compares native workflows with a common hand output contract.

The primary score uses the original source frame. The supplementary score treats decoded-identical frames as equivalent on these static fixtures and appears separately in the CSV. A missed frame contributes to the all-target quality denominator. MPJPE averages only matched hands.
