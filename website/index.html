02 / The workflow

Connected, from the first frame.

A small set of model branches, with explicit dependencies and checked outputs at every stage.

ConfigureChoose supported branches and provide the required model and data assets.

RecoverResume unchanged runs from valid stage commits when work is interrupted.

InspectRead Parquet and NPZ outputs, quality checks, and an offline run report.
