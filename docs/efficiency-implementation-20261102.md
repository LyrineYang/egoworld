## 最终集成结果

当前工作区已切到 `codex/data-quality-efficiency`，包含本任务实现和另一任务 `3e2aa5d` 的全部已提交更新；main 引用保留 `529a175`，最终提升由用户安排。
当前分支生产 Python 文件与原生验收快照逐字节匹配；源码、配置、原始结果和首次失败尝试均留档 D 盘。
完整适用回归为 **297 passed / 11 deselected**，包括真实 Ray、诊断/恢复、清洗/缓存和另一任务的 CPU pilot 验收。

- **真实手部**：12 条手姿态、6 条右手机器人映射，与此前 release 样例的关节、相机平移、MANO 和机器人值最大差均为零。
- **世界输出**：3 个相机、3 个物体姿态、5459 个过滤世界点；3cm 门槛下预留内点率约 59.6%、预留内点 RMSE 约 1.71cm。该误差仅针对预留内点，不是全图或真实轨迹精度。
- **随机性边界**：Fast3R 配置启用上游随机视图位置编码；未固定种子的两次世界重建不要求逐点相等，也不将点数差异算作优化收益。公平阶段对照可使用诊断 `--seed`，仍需单独核查质量。
- **登记后命中**：真实短样例约 2–4 秒，模型阶段 computed 为空；当前分支 provenance 约 0.09–0.22 秒。默认 strict 保留全内容校验，这不是无条件算法加速或跨硬件吞吐结论。
- **坏输入**：真实有效样例 + 同内容副本 + 损坏文件 + 空白视频，仅保留有效样例；全部坏输入约 0.19 秒返回 rejected。
- **分支过滤**：显式过高面积门槛验证 HaMeR/Dex 都被过滤且不加载权重，boxes 保留，按请求覆盖返回 partial。
- **左手 CPU-only**：在 Ray 显式报告 0 GPU 的集群中命中 SAM/HaMeR，仅重算 Dex，得到 6 条左手机器人映射；左右手独立 URDF/FK 检查通过、限位越界均为零。
- **实际共享输入**：关闭阶段缓存读取的 combined_rgb4 真实整链全部通过；HaMeR 命中 Fast3R 已请求的共同帧，frame hit=1。没有把阶段结果缓存当作解码缓存收益。
- **清理**：phase-spool/input-cache 临时数据数组零残留；模型、源视频和已提交结果保留。

内存机制限制新引入的采样统计、行批次、输入缓存和中间块，不是对第三方模型私有堆、OS 页缓存、所有片段排序/结果列表或整机 RAM 的硬上限。
完整模型的 Data-Juicer 吞吐/质量比较仍需后续实验；本轮交付对照入口、身份/覆盖检查，并保留已并入的 CPU 契约清洗 pilot，不声称生产 EgoWorld 已优于 Data-Juicer。
