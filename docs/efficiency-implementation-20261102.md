## 已有观测

主工作区首轮适用回归为 201 passed / 11 deselected，后续新增更细测试仍需最终合并后回归。
第一轮临时集成发现旧诊断夹具将 rows 作为列表使用：已保留兼容 helper，生产改用 iter_rows。
另两处是临时快照缺 Git 元数据、Ray worker 缺测试模块路径，已修正测试环境；未将失败试验删除。
修正后的完整隔离回归为 274 passed / 11 deselected。

主工作区真实手部链得到 12 条手姿态、6 条机器人映射；与既有 release 样例各数值列最大差为零。
独立 Pinocchio 复核：严格限位越界 0，FK 有效。
后续 strict 全命中为 3 个模型阶段命中、computed 为空、projection 命中；入口约 18.49 秒，provenance 约 16.09 秒。
这是默认严格验证的真实成本，不将“零模型计算”表述为零工作；早期测量期间有其它集成测试，不能当隔离吞吐基准。
这些记录对应 `native/main-source-snapshot`，最终集成版本另存，不覆盖早期证据。
