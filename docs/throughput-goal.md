## 实施约束

1. 逻辑阶段和 schema 3 不变；CPU/GPU 内部步骤是执行实现，最终 Writer 提交才解锁下游。
2. 拆分路径显式启用；沿用内置 worker 和受监护的 RunnerSession，隔离模型环境照常使用。
3. 大数组放在 worker 引用或有预算临时块中。输入/中间结果由统一生命周期管理，失败不能遗留不可回收额度。
4. HaMeR 保持官方裁剪与坐标修正；SAM2/FP 保持每片段/对象的时序状态。Fast3R 保留 JPEG/官方 loader 的像素语义，除非独立实验支持替换。
5. 代价策略仅改变可行任务及空闲 worker 的选择，不自动改变 worker 数、batch、精度、采样或配置文件。
6. 实测收益不是预设结论；保留退化对照，限定本机证据范围。CPU 模拟资源测试不能宣称已完成多 GPU 硬件扩展验证。
