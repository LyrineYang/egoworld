# EgoWorld documentation

EgoWorld turns egocentric video into inspectable hand, object, and scene data. This English collection explains the project, the research questions, and how to begin.

| Start here | What you will find |
| --- | --- |
| [Getting started](getting-started.md) | Installation, configuration, a short run, recovery, and inspection |
| [Architecture](architecture.md) | The processing graph, output contracts, and recovery model |
| [Insights](insights.md) | The ideas behind output selection, reuse, geometry, and efficiency |
| [Research plan](research-plan.md) | Testable hypotheses, baselines, ablations, and acceptance criteria |
| [Implementation status](status.md) | What is on the public branch, in development, and still unproven |
| [Website design](../website-design.md) | Visual direction, content structure, and the future website handoff |

The detailed [server guide](../server.md), [output reference](../outputs.md), [scheduling design](../design.md), and [test records](../testing.md) are maintained in Chinese. Historical notes under `docs/archive/` describe earlier intentions and are not a current feature list.

The integration branch also documents [replay and GPU probes](../replay.md), [phase execution](../throughput-execution.md), [single-GPU validation](../throughput-validation.md), and the [equal-input/output benchmark protocol and pilot](../equal-work-benchmark.md).
